# 💈 Estilo Livre - Landing Page de Barbearia

Landing page moderna, estilosa e totalmente responsiva desenvolvida para o segmento de barbearia. O projeto apresenta uma interface limpa, focada em conversão, destacando serviços, diferenciais e facilidade de agendamento para os clientes.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:

* **HTML5**: Estruturação semântica do conteúdo.
* **CSS3**: Estilização avançada, layout responsivo e efeitos visuais.
* **Git & GitHub**: Controle de versão e hospedagem do site via GitHub Pages.

---

## 📱 Funcionalidades

* **Design Responsivo**: Adaptado perfeitamente para visualização em computadores, tablets e smartphones.
* **Seção de Serviços**: Apresentação clara dos cortes, barba e cuidados oferecidos.
* **Seção Sobre**: História e essência da barbearia para gerar conexão com o público.
* **Chamada para Ação (CTA)**: Botões estratégicos para facilitar o contato e agendamento.
